# Что впереди

Только то, что ещё не сделано. Сделанное уходит в заметки выпусков, решения — в [журнал](decisions.md).

## Ближайший выпуск: 1.59.0

- Первый шаг реселина Android.
- Hysteria2 с обфускацией без маскировки под Chrome: меньше пробуждений радио в покое.
- Минимальная версия клиента (raycontrol client-min-v1): заголовок `X-Raycontrol-Client` во всех запросах к узлу;
  при отказе по версии строки профилей остаются, а карточка говорит, что нужно обновиться.

## Порядок в репозитории

- Свои шаблоны issue на русском и английском.
- Своя замена `libneko` (у него нет лицензии).
- Экран лицензий в приложении и `NOTICE`.

## Android до MVP

- Реселин по шагам, каждый шаг — выпуск 1.60, 1.61 и далее, целиком до v2.0.0.
- `UPDATE.json` в выпуске: обязательное обновление и минимальная поддерживаемая версия.

## Компьютер до MVP

- Матрица требований: 38 ID из описи функций и колонка «Окно» ([требования](spec/desktop-requirements.md)).
- Этап 3, срезы 2–8: хранилище, импорт ссылок и подписок, узлы raycontrol, сборка конфига в Go
  ([этап 3](design/desktop-stage3.md)).
- Упаковка для Linux и Windows.

## v2.0.0 (MVP)

- Android и компьютер одним выпуском, VERSION_CODE 2000.
- Отсечение старых сборок на узлах по минимальной версии.
- Донаты.
- Старые выпуски удаляются, когда тестеры перейдут на новые.

## В запасе

- Interop локальной сети: «телефон → ноутбук, открытый всем» дважды не дошёл.
- Пункты для клиента из ревью mihomo, когда по ним будет решение.
- Редкий сбой e2e: туннель Hysteria2 перестал отвечать во время проверки Private DNS.
