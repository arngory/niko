# Что впереди

Только то, что ещё не сделано. Сделанное уходит в заметки выпусков, решения — в [журнал](decisions.md).

## Ближайший выпуск: 1.63.0

- С raycontrol v0.35.0: spa-v3 (адрес назначения в подписи стука), короткое приглашение RCINV3 и ретранслятор по
  имени (`via_links`).
- С тем же пином: строки XHTTP interop с целью REALITY на OpenSSL из отчёта становятся проверками (форк Xray ноды
  больше не подтверждает SNI, и цель с пустым EncryptedExtensions проходит).

## Android до MVP

- Экраны по макетам, после перекраски (она закончена в 1.62; [платформы](ui/platforms.md), шаги 3 и 5):
  - сначала проба общего слоя: один экран-список из одного описания на Android, на Flutter и макетом, замер памяти
    Views против Compose; по её итогам владелец выбирает вариант А или В;
  - затем экраны Android по макетам, по экрану за выпуск с 1.63: главная с видами «Простой» и «Расширенный»
    (карточка подключения, плитки), узлы и профили, настройки, подписки и группы, журнал и инструменты. Каждый
    экран сверяется с холстом по ID и снимается Paparazzi;
  - все экраны — до v2.0.0: Android и компьютер выходят с одним дизайном.
- «Поддержать проект» в «О программе», когда выбраны площадки.
- Снимки экранов для README.
