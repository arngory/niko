## Android до MVP

- Экраны по макетам, после перекраски (она закончена в 1.62; [платформы](ui/platforms.md), шаги 3 и 5):
  - экраны Android по макетам на Compose (решено 2026-11-20, [проба](research/ui-probe.md)), по экрану за выпуск,
    как в плане выше. Каждый экран сверяется с холстом по ID и снимается Paparazzi;
  - экраны-списки — руками на каждой платформе, на общих токенах, компонентах по канве и текстах (вариант А,
    решено 2026-11-21 по [пробе](research/list-screens-probe.md));
  - все экраны — до v2.0.0: Android и компьютер выходят с одним дизайном.
- «Поддержать проект» в «О программе», когда выбраны площадки.
- Снимки экранов для README.

## Компьютер до MVP

- Этап 3, срезы 3–11, как в плане выше: ссылки, хранилище, окно, сборка конфига в Go, TUN, подписки, правила, узел
  по приглашению ([этап 3](design/desktop-stage3.md)).
- Без установщика: сборки для Windows и Linux архивом. Проверки окружения при запуске и в работе: путь и имя
  пользователя не в ASCII (кириллица) и с пробелами, длинные пути и права на Windows; на Linux — каталоги XDG,
  `noexec` на временном каталоге, права на TUN, файловые системы без учёта регистра. Что не так — сказать словами,
  не падать.
- Свой репозиторий — когда устоится основной путь `NikoService` (профили, импорт, подключение; срезы 4–7).

## В запасе

- Первый контакт в Yggdrasil иногда стоял минуту: ironwood не повторял ack на повтор того же init (причина сбоя
  interop локальной сети, [заметка](research/ironwood-init-stall.md)). Исправлено в форке arngory/ironwood, клиент
  на нём; niko-server подключает форк сам.
- Ревью mihomo (raycontrol `docs/research/mihomo-review.md`): клиентские пункты 5 и 8 сделаны (сторож по отказам
  соединений, замер keepalive). Клиентские части п. 1 (наборы правил через ноду) и п. 7 (живые соединения для
  администратора) — после спецификаций сервера.
- Редкий сбой e2e: туннель Hysteria2 перестал отвечать во время проверки Private DNS.
