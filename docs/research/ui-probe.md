# Проба: экраны Android на Views или на Compose

Решение владельца 2026-11-20: прежде чем переносить экраны из макетов в приложение, замерить, во что обходится
каждый способ рисования. Первым переносится главная с навигацией ([платформы](../ui/platforms.md), шаги 3 и 5).

## Что сравнивается

Один экран из макетов — «Главная · Простой» (артборд P-Simple на холсте Niko, D-MAIN) — нарисован дважды, с теми
же статическими значениями:

- `ui/probe/ProbeViewsActivity.kt` и `res/layout/probe_simple.xml` — Views, как остальное приложение сейчас;
- `ui/probe/ProbeComposeActivity.kt` — Compose: только `foundation` и `ui`, без Material (дизайн-система рисует
  свои компоненты), BOM 2024.10.01.

Оба берут цвета, отступы и шрифты из ресурсов, которые генерирует `shared/tokens.json`. Ни службы, ни базы: только
сам экран. Обе активности открываются лишь из оболочки adb (требуют `android.permission.DUMP`, его нет ни у одного
приложения).

## Как меряется

`.github/scripts/ui-probe.sh` в задании smoke (`ci.yml`), на эмуляторах API 29 и 35, сразу после smoke.sh:

- каждый экран запускается холодным, в своём процессе, по три раза вперемешку с другим экраном и с нынешней
  `MainActivity` для масштаба;
- время запуска — `TotalTime` из `am start -W`;
- память процесса окна через 5 с — `dumpsys meminfo` (TOTAL PSS, Java, Native, Code, Graphics; RSS — с Android 11,
  на API 29 его нет);
- размер каждого APK и его dex.

Итог — таблица медиан в сводке задания и артефакт `ui-probe-api<уровень>` с сырыми цифрами и снимками обоих экранов.

## Итоги

Прогон CI на `67b95f5` (arngory/niko#63), 2026-11-20, медианы трёх холодных запусков:

| | Views | Compose | разница | нынешняя `MainActivity` |
|---|---|---|---|---|
| Android 15 (API 35), запуск | 716 мс | 784 мс | +68 мс (+9 %) | 1022 мс |
| Android 15, PSS | 50,5 МБ | 51,5 МБ | +1,0 МБ (+2 %) | 53,5 МБ |
| Android 15, RSS | 158,2 МБ | 160,6 МБ | +2,3 МБ | 164,3 МБ |
| Android 10 (API 29), запуск | 629 мс | 677 мс | +48 мс (+8 %) | 742 мс |
| Android 10, PSS | 58,4 МБ | 59,0 МБ | +0,6 МБ (+1 %) | 63,3 МБ |

APK arm64: 32 872 608 байт у v1.62.0 и 33 777 736 со сборкой пробы, dex — 5 292 592 и 6 208 164. Compose
(foundation, ui, runtime, animation) добавляет около 0,9 МБ к каждому APK. Служба VPN живёт в своём процессе
(`io.niko:bg`), её память это не трогает. Обе пробы легче нынешней главной из NekoBox.

## Решение

Владелец, 2026-11-20: новые экраны Android — на Compose, на `foundation` без Material, тема Niko из тех же токенов
(`shared/tool/gen_tokens.py` пишет `ui/compose/NikoTokens.kt`, `ui/compose/NikoTheme.kt` выбирает тему по ночному
режиму). Старые экраны на Views уходят по одному, по мере того как их заменяют экраны по макетам; первая — главная с
навигацией. Задержку первого запуска Compose можно сократить базовым профилем (baseline profile), это отдельная
задача.

Сама проба (обе активности и `ui-probe.sh`) удалена после замера в том же arngory/niko#63; её код остаётся в
истории, в коммите `a55c87a`.
